# Rasmali's Palace 👑🏰✨

A pastel fairytale storybook and interactive web experience.

## 🌸 Features
- Interactive fairytale storybook scenes
- Ambient background music (`assets/song.mp3`)
- Elegant animations and photo moments (`assets/p1.jpg` – `assets/p5.jpg`)
- Mobile-first, responsive design

## 🚀 Live Demo & Usage
Simply open `index.html` in any modern web browser, or host with GitHub Pages!
